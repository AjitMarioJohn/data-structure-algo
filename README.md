# data-structure-algo

DSA mastery, learn-by-doing. Java. Goal: interview-ready (Google / Netflix / Walmart).

## How it works
Each topic ("node") taught in **three tones**, in order:
1. **Good Teacher** — deep teach, basic→advanced, theory + practical.
2. **Harsh Senior** — build a real app, no spoon-feeding.
3. **Arrogant Architect** — adversarial grilling; beat him to clear the node.

Beat tone 3 → node clears, next unlocks. Goal = design intuition, not memorization.
